## What the extra Threadripper money buys

### Threadripper advantages

- Much more PCIe connectivity and stronger lane topology
- Superior multi-GPU platform
- Quad-channel ECC RDIMM
- Substantially higher memory capacity
- Better expansion capability and long-term workstation flexibility
- Easier path to 256GB, 512GB and beyond

### AM5 advantages

- Much cheaper platform
- Better gaming-focused CPU
- Lower CPU power and cheaper cooling
- Cheaper motherboard, RAM and case
- 128GB remains substantial system memory

### AM5 compromises

- Dual-channel memory
- 128GB 2x64GB is the preferred configuration
- Two GPUs operate PCIe 5.0 x8/x8, not x16/x16
- Much fewer total PCIe lanes
- `M.2_2` shares lanes with the second GPU; it must remain empty for x8/x8
- Less future workstation expansion
- 256GB 4x64GB places substantially more load on the memory controller and has an official DDR5-3600 four-DIMM support point

## Locked architecture notes

- Track A remains the existing Threadripper 9960X / TRX50 / 256GB ECC RDIMM / Elite Server workstation. It is not replaced by Track B.
- Track B primary CPU is the 9950X3D. The distinct 9950X3D2 Dual Edition is monitored separately and must never be substituted automatically.
- Track B storage uses the 9100 PRO in `M.2_1`, leaves `M.2_2` unused, and places the 990 PRO in chipset-connected `M.2_4` to preserve dual-GPU x8/x8.
- Track B AIO is top-mounted exhaust. Its 396x120x27mm radiator plus 25mm fans gives a nominal 52mm stack; check motherboard shroud clearance before purchase.
- Both tracks use identical RTX 5090 pricing. Two RTX 5090s remain separate 32GB devices; supported sharding or parallelism is required.
