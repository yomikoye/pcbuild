## Evidence quality and collection method

Ordinary Python requests GET + BeautifulSoup rendered HTML/JSON-LD was tested and worked on Morele, ALTERNATE, Geizhals EU, Ceneo and PHS. Web search supplied discovery/index evidence, never treated as checkout confirmation. No native web extraction used. Requests were read-only; no baskets, accounts or orders changed.

Quality: **R** = direct retailer HTML/structured offer; **M-index** = official manufacturer result indexed in search, not extracted live document; **C** = comparison data; **S** = specialist's own compatibility claim. A catalog identity, generic capacity support, search result or model configurator URL is not an exact QVL row.

Blocked HTTP responses were not bypassed. G.SKILL QVL, GIGABYTE support, Kingston configurator/part pages, CompuRAM, Proshop, Pangoly, Memory.NET and Smicro returned 403; Geizhals DE returned 429; old Cenowarka exact link returned 410. Browser fallback failed before page navigation because npm cache contains root-owned files (EACCES); no ownership/configuration changes attempted. Kingston PDFs returned HTTP 200, but neither pypdf nor pdftotext was installed; PDF content claims below are therefore explicitly indexed manufacturer evidence, not locally parsed PDFs.
