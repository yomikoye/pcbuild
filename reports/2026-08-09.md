### Track B CPU and RAM interpretation

- The 9950X3D remains primary.
- The distinct 9950X3D2 Dual Edition has 3D V-Cache on both CCDs, 208MB total cache, 5.6GHz boost and 200W TDP. Its current Polish-VAT reference is 2,061.99 PLN above the 9950X3D. Do not substitute automatically; compare compile, creation and cache-sensitive workload value each week.
- Kingston `KF556C40BBK2-128` is exact ASUS-QVL validation for 2x64GB DDR5-5600. Current 8,780.51 PLN pricing is also unusually high, but it is the strongest evidence-backed stability choice.
- The optional 256GB experiment uses four 64GB modules and should begin at DDR5-3600. Two separately packaged 2x64GB kits are not equivalent to a factory-matched four-DIMM kit.

### Track B lane and storage rules

- With both CPU-fed GPU slots populated, the board operates PCIe 5.0 x8/x8, not x16/x16.
- `M.2_2` shares CPU lanes with the second GPU slot. Enabling it can reduce the second GPU to x4.
- Leave `M.2_2` empty.
- Install the 9100 PRO in `M.2_1` and the 990 PRO in chipset-connected `M.2_4`.
- The third physical x16 slot is chipset-connected PCIe 4.0 x4 and is not the second primary GPU slot.

### Track B cooling and PSU rules

- NAUTILUS radiator: 396x120x27mm; fans: 25mm; nominal stack: 52mm.
- The Pro 2 Server family supports a top 360 radiator and a 120x475mm envelope. Verify motherboard VRM/I/O shroud clearance against the documented 55mm component envelope.
- Top AIO fans exhaust; 3x140 front and 3x120 side intake; 1x140 rear exhaust. Do not populate every optional location initially.
- B1 uses the verified PRIME PX-2200 for future dual GPU.
- B2 uses a cheaper VERTEX GX-1200 listing for the one-GPU-only calculation, but Morele labels this exact offer ATX 3.0. Confirm the exact revision and GPU-side cable before purchase while continuing to search for an unambiguous ATX 3.1/12V-2x6 value offer.

## What the extra Threadripper money buys

### Threadripper advantages

- Much more PCIe connectivity
- Superior multi-GPU platform and lane flexibility
- ECC RDIMM
- Quad-channel memory
- Substantially higher memory capacity
- Better expansion capability
- Easier path to 256GB, 512GB and beyond
- Better long-term workstation flexibility

### AM5 advantages

- Much cheaper platform
- Better gaming-focused CPU
- Lower CPU power
- Cheaper cooling, motherboard, RAM and case
- 128GB remains substantial system memory

### AM5 compromises

- Dual-channel memory
- Preferred configuration is 128GB 2x64GB
- Two GPUs run PCIe 5.0 x8/x8, not x16/x16
- Much fewer total PCIe lanes
- M.2/GPU lane-sharing constraints
- Less future workstation expansion
- Four-DIMM 256GB operation imposes more memory-controller load and lower official speed

## Compatibility and warranty alerts

1. Track A is not replaced or reduced; both tracks remain independent.
2. Track B is x8/x8 with two GPUs. It is never x16/x16.
3. `M.2_2` must remain unused in Track B's dual-GPU layout.
4. Exact Track B case `PH-ES620PC_BK03` has no verified live offer; BK02 is a reference only.
5. Two RTX 5090s remain separate 32GB devices and require software-supported sharding/parallelism.
6. Track A's current total is distorted by RDIMM availability; Track B RAM is also unusually expensive.
7. PRIME PX-2200 is fixed 230V and rated 15A input. Verify circuit, socket, breaker, cable and concurrent room load.
8. Update ProArt X870E-CREATOR BIOS before installing 9950X3D2.
